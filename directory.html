Tier 01 — Live

Management Board

The six department Chiefs who make up A-HOUSE's C-suite, each reporting directly to the CEO and owning one department end to end.

Tier 02 — Live

Executive Board

Heads run each department day-to-day and report directly to their Chief to operationalize the hub's overarching strategy.

Beyond the board

Project Teams

Outside the two-tier board, recruitment drives pull members from the general pool into short-term project teams — each formed around a single A-HOUSE project rather than a standing department.

LEADS THE PROJECT

Project Manager

Owns the project end to end — scoping the work, assigning tasks across the Core Team, keeping the timeline on track, and reporting progress back to the relevant department Head.

STAFFS THE PROJECT

Core Team

Members recruited for that project specifically — however many the scope needs. They carry out the day-to-day work under the Project Manager for the duration of that one project.
